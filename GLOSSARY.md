# GDGoC Mapúa Website

The public website of Google Developer Groups on Campus – Mapúa University: chapter info, events, a shop, and community spaces where members post content that Moderators review.

## People

**Member**:
A person with a signed-in account on the site.
_Avoid_: User (when meaning a person), account, student

**Moderator**:
A Member with admin rights who reviews Submissions and manages site content.
_Avoid_: Admin (when meaning the person), officer (when meaning the permission)

**Officer**:
A chapter officer whose profile is shown on the About Us page. Being an Officer grants no permissions; that's what being a Moderator means.
_Avoid_: Moderator, admin

## Events

**Event**:
A chapter activity such as a workshop, hackathon, sprint, talk or social, published on the Events page.
_Avoid_: Activity, session (when meaning the whole event)

**Upcoming event** / **Past event**:
An Event whose start time is still ahead, or already behind. This follows from the date alone and is never set by hand.
_Avoid_: Current event, previous event, coming soon

**Featured event**:
An Event that a Moderator has picked to headline the Events page. It can be upcoming or past.
_Avoid_: Highlight, pinned event

**Event category**:
The kind of Event: Workshop, Hackathon, Sprint, Talk or Social.
_Avoid_: Type, tag

## Community content

**Wall Post**:
A Submission to the Freedom Wall: a short message with a background color, a category, an optional image and up to three Stickers.
_Avoid_: Message, note, confession

**Event Quote**:
A Submission giving a Member's thoughts on a specific Event, shown on that Event once approved.
_Avoid_: Testimonial, feedback, review

**Sticker**:
A GDGoC-themed graphic from a fixed set that a Member can add to a Wall Post.
_Avoid_: Emoji, badge

**Submission**:
Any content a Member sends in that a Moderator has to review before the public can see it.
_Avoid_: Entry, request

**Review status**:
Where a Submission stands: _pending_ (waiting for review), _approved_ (public), _rejected_ (never shown, with a reason only the author sees) or _removed_ (was approved, then taken down).
_Avoid_: State, visibility

**Anonymous**:
A Submission that hides its author's name from the public. Moderators can still see who wrote it.
_Avoid_: Private, hidden
